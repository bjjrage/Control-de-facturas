# Learned routines V1

No hay skills, rutinas ni hábitos activos en esta versión.

Este directorio es únicamente un lugar de registro para futuras propuestas. El loader de conocimiento no ejecuta rutinas, no cambia prompts por historial y no aprende automáticamente de las conversaciones.
