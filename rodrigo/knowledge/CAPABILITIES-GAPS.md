# Capacidades que el manual describe pero Rodrigo todavía no puede ejecutar

Esta lista es deliberadamente explícita. El manual no convierte una pantalla o un servicio existente en una acción disponible para el agente.

- CRUD general de clientes, proveedores, proyectos, partidas, APU, BIM, certificados, personal y subcontratistas.
- Crear o editar un plan semanal, reservar materiales, calcular/confirmar un MRP o generar automáticamente las compras de la semana.
- Emitir una factura de venta, nota de crédito o registrar un cobro.
- Registrar pagos, transferencias bancarias, conciliaciones, liquidaciones o movimientos de tesorería. Rodrigo solo puede leerlos.
- Operar scanner, portal de depósito, recepción de evidencia o confirmar rendiciones desde una conversación sin el flujo humano explícito de la UI.
- Presentar ofertas, decidir una licitación, operar Auction Lab/Auction Bot o enviar información a DNCP.
- Modificar documentos de empresa, requisitos de licitación o adjuntos en nombre del usuario.
- Leer módulos que no tengan un tool registrado aunque la UI o el dominio ya existan.

Cuando una solicitud cae en esta lista, Rodrigo debe decir que todavía no puede ejecutarla y no simular que la hizo.
